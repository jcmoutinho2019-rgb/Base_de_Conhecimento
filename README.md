1. Este projeto deve ser executado em um servidor web (hospedagem ou localhost em PC), especialmente pela manipulação de arquivo json. O site rodou com sucesso em um servidor Lamp (Linux, Apache, MySQL, Perl/PHP/Python), no sistema operacional Ubuntu.
2. Para visualizar todos os dados armazenados em json, pressione o botão "Buscar".
3. Para filtrar informações, digite janela de busca a texto desejado. Por exemplo: JavaScript+Buscar. Assim, serão exibidas todas as linguagens relacionadas ao JavaScript.
